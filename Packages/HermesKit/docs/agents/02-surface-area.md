# HermesKit: user and caller surface

## Implemented today

Public model types in Sources/HermesKit include AppModel, Contact, ChatThread, RoomThread, Routine and authentication/address types. ChatThread.send(_:attachments:) uploads `Attachment`s first (images through `image.attach_bytes`, which queues them for the next turn; every other file, PDFs included, through `file.attach`, which returns an `@file:` reference), then submits; a failed upload sends nothing, takes queued images back with `image.detach` and adds a notice. A sent message carries `@image:`/`@file:` lines after its text, as the gateway's history does; `AttachmentRef.split` reads them back. `sentImages` keeps this run's uploaded image bytes by gateway path for thumbnails. Limits: 25 MB per image (the gateway's), 50 MB per file. AppModel exposes restore/signIn, `AppModel.demo()` (Debug only: a signed-in model with made-up agents, chats, a pending approval, a room and routines, built from the internal `sample` helpers; it never connects), `setForeground(_:)` (closes the socket while the app is in the background and reconnects on return, reattaching every chat; the iOS app calls it from `scenePhase`) and per-contact thread/room/routine operations. GatewayConnector mints a WebSocket ticket, opens /api/ws, waits for gateway.ready, then advertises server_requests capabilities. JSONRPCChannel owns socket requests and responses. OfflineCache persists a Codable roster/thread snapshot; KeychainTokenStore persists token sets per gateway.
